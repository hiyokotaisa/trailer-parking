# TRAILER / PARK

PC向けの2D見下ろし型トレーラー駐車ゲームのデモです。HTML / CSS / JavaScript / Canvasだけで動作し、依存ライブラリやビルドは不要です。

## 起動

`demo/dist/index.html` をChrome、Edge、Firefox、Safariなどのブラウザで開いてください。ローカルサーバーを使用する場合は、プロジェクトのルートで次のコマンドを実行します。

```sh
python3 -m http.server 8000 --directory demo/dist --bind 127.0.0.1
```

その後、`http://127.0.0.1:8000` を開きます。

## 操作

| キー | 操作 |
| --- | --- |
| ← / → または A / D | ハンドルを回す（離すと角度を保持、反対方向で手動で戻す） |
| ↑ または W | アクセル |
| ↓ / S / Space | ブレーキ |
| E | 前進 D / 後退 R を切り替え（停車中） |
| Enter | 開始 / 一時停止から復帰 |
| Esc | 一時停止 / 復帰 |
| R | コースをリトライ |

右側で車両とコースを選択できます。変更すると走行は最初からになります。ギアは画面下のD / Rボタンでも変更できます。

## 車両

| 車両 | 全長の目安 | 総重量の設定 | 操作感 |
| --- | --- | --- | --- |
| 標準トレーラー | 12.0 m | 18 t | 基本的な加速・制動・ハンドル操作 |
| タンクローリー | 16.5 m | 36 t | 加速とハンドル操作が遅く、惰性・制動距離・内輪差が大きい |

寸法と重さはゲーム用の簡易設定です。加減速には車両ごとの駆動力・制動力を重量で割った値を使用します。トレーラーの長さに応じて軸位置、描画、衝突判定、駐車枠も変わります。

## ルール

- 初回のアクセル操作でタイム計測を開始します。
- トレーラー部分の全体を緑の駐車枠に収め、方向をそろえて2秒間停止するとクリア。牽引車を枠に収める必要はありません。
- 障害物・縁石・車両・コーンへの接触は1回につき5秒加算。接触中の連続加算は行いません。壁を抜けることはできません。
- 牽引車とトレーラーの連結角度は左右98°まで。画面下に角度を表示し、85°以上で注意色になります。限界では、それ以上角度が開く動きを止めます。ハンドルを戻して前進すると姿勢を修正できます。
- 結果に走行タイムとペナルティを表示し、車両・コース別の自己ベストをこのブラウザに保存します。初期デモの記録は標準トレーラーの記録として引き継ぎます。オンラインランキングはありません。
- タブを離れたり操作説明を開いたりすると、自動で一時停止します。

## コース

1. **物流センター**：広い構内で基本の前進・駐車を練習。
2. **工業団地の狭路**：狭い直線と連続する直角カーブ。内輪差に注意。
3. **搬入口へのバック**：駐車済みトレーラーの間の搬入口へ切り返して駐車。
4. **給油所の裏路地**：コンテナで狭まる裏路地、クランク状の通路、給油設備を避けて奥の駐車枠へ。長い車両では切り返しが必要です。

`demo/dist/physics.js` に車両の寸法・コース・障害物・駐車枠・衝突判定をまとめています。`game.js` は描画と操作、タイム・結果管理を担当します。

牽引車の自転車モデルと、ヒッチの移動に追従するトレーラーの運動学を120Hzの固定刻みで計算します。内輪差、バック時の連結角度の増加、重量による加減速の違い、ジャックナイフを再現した簡易モデルです。タイヤの横滑り、タンク内の液体の揺れ、サスペンションなどの厳密な力学は含みません。

PCの物理キーボードを前提としたデモです。スマートフォンでは画面は表示できますが、タッチ運転には対応していません。

## 検証

Node.jsがある環境では `node --test demo/tests/physics.test.cjs` で車両運動、ブレーキ、接触判定、駐車判定、ジャックナイフからの復帰を検証できます。ゲーム自体にはNode.jsは不要です。

Chromeでキーボード操作、ギア切替、タイムの一時停止、接触ペナルティ、2秒間の駐車判定、記録保存、画面幅への対応を確認しました。

ブラウザが対応している場合のみ、補助的なWebMCPツール（走行状態の読み取り・コース選択）を登録します。今回のChromeには対応コンテキストがなく、ネイティブWebMCPの検証は未実施です。
